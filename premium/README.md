# SETOR GMAIL Premium

Aplikasi web interaktif full-featured dengan desain **iOS Liquid Glass × Premium SaaS**.

## Wajib Daftar → Login

Pengguna harus **daftar dulu**, lalu **login** untuk masuk ke dashboard.

## Fitur

- Landing page + statistik
- Auth: Daftar (username, gmail, password, konfirmasi) & Masuk
- Dashboard statistik + grafik 7 hari (Chart.js)
- Formulir setor Gmail (tanpa password/OTP)
- Riwayat + search + filter status + detail timeline
- Admin panel (`admin112` / `12345678_`)
- Bottom nav mobile, dark liquid glass UI
- Lucide icons
